# Moderation Dashboard (Node.js / Discord.js v14)

This Node.js implementation provides an interaction-first moderation dashboard with:

- `/automod`
- `/logs`
- `/moderation`
- `/config`
- `/security`

And interactive workflows via buttons, select menus, and modals.

## Run

```bash
npm install
cp .env.example .env
npm run deploy
npm start
```
